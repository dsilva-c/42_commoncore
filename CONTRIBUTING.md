# 🤝 Contributing

This is my personal progress repository for the **42 Porto Common Core**
curriculum. It exists to track my own coursework, so I'm not looking for
external pull requests against project solutions.

That said:

* Spotted a bug, typo, or broken link? Feel free to
  [open an issue](../../issues) — I'm happy to hear about it.
* Please don't open PRs that solve exercises for me; per 42's academic
  integrity rules, this code needs to stay my own work.
