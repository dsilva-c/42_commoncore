# 🔒 Security Policy

This repository contains coursework for the **42 Porto Common Core**
curriculum — school exercises, not production software. That said, if you
spot something that looks like a real security issue (e.g. in a shared
script or tool), I'd like to know about it.

## Reporting a Vulnerability

Please open a [private security advisory](../../security/advisories/new)
or reach out directly at d.g.s.cardoso2002@gmail.com rather than filing a
public issue. I'll aim to respond within a few days.
